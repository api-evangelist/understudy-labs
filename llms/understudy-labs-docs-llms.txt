# Understudy docs

> Docs for the Understudy LLM gateway, control plane, capture pipeline, routing, managed models, Desktop, and open-source agent tools.

Understudy is an LLM gateway and optimization platform. The docs cover the drop-in Anthropic/OpenAI-compatible gateway, request capture, project/workload scoping, model routing, managed catalog calls, control-plane APIs, Desktop, portable local task models, and the open-source agent tools used to collect evidence and run optimization loops.
